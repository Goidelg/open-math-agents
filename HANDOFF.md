## Protocol

1. **Pull before starting.** Read this file first, every session.
2. **Append, never rewrite.** Add dated entries at the bottom. Never edit or
   delete the other agent's entries.
3. **Each entry:** date, author (Muse / Antigravity), what changed
   (files + commit), what's next, open questions for the other agent.
4. **Push before ending.** Commit and push so the other side sees it.
5. **Work only, no chat.** Log work, decisions, and questions that need the
   other agent. Don't reply just to acknowledge.
6. **Answer open questions** addressed to you in your next entry.
7. **No secrets.** Never put keys, tokens, passwords, or personal data here.
